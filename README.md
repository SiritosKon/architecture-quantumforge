# architecture-quantumforge

Проектная работа 7 спринта — RAG-бот по корпоративной базе знаний для компании **QuantumForge Software**.

Бот на основе Retrieval-Augmented Generation (RAG) быстро и точно отвечает на вопросы
сотрудников по внутренней документации, честно сообщает «Я не знаю», когда ответа в базе
нет, и устойчив к промпт-инъекциям в документах.

## Карта заданий

- **Задание 1** — Исследование моделей и инфраструктуры (LLM, эмбеддинги, векторные БД, выбор сервера).
- **Задание 2** — Подготовка уникальной базы знаний (30+ документов + словарь замен `terms_map.json`).
- **Задание 3** — Векторный индекс базы знаний (эмбеддинги + FAISS).
- **Задание 4** — RAG-бот с техниками промптинга (Few-shot, Chain-of-Thought).
- **Задание 5** — Запуск, демонстрация и защита от промпт-инъекций (10 обращений).

Все ответы по заданиям — в [`Project_template.md`](./Project_template.md).

## Структура репозитория

| Путь | Назначение |
|---|---|
| `Project_template.md` | Главный документ с ответами по всем заданиям |
| `knowledge_base/` | База знаний: 30+ документов + `terms_map.json` (Задание 2) |
| `scripts/` | Скрипты подготовки данных: скачивание, очистка, замена терминов (Задание 2) |
| `src/` | Код: построение индекса и RAG-бот (Задания 3–4) |
| `index/` | Артефакты векторного индекса FAISS (Задание 3) |
| `screenshots/` | 10 скринов работы бота (Задание 5) |
| `Dockerfile`, `docker-compose.yml` | Упаковка бота (бот + FAISS) |

## Запуск

Инструкции по установке окружения и запуску бота появятся по мере выполнения заданий
(см. соответствующие разделы в `Project_template.md`).
